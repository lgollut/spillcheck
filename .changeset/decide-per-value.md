Decide once per value instead of reviewing each appearance. A value now asks "Does this need rotating?" and offers Test or dev only, Not a secret, Needs rotation, or, from the menu, Real, but keep it. The answer covers every appearance of that exact value, including later ones: a value you dismissed no longer comes back for review when an agent prints it again, and only its count of new appearances grows. A value that needs rotation waits under To rotate and still alerts in new conversations until you mark it rotated or revoked. After a decision, the next value to review opens. Removing a value's retained content keeps your decision. Earlier reviews carry over: a value with an appearance you confirmed as a secret needs rotation, and one whose appearances you all marked as not a secret stays dismissed.
