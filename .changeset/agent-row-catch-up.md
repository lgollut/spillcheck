Show which agent is catching up. While Spillcheck reads the last seven days of history, Coverage now marks the agent being read with a "Catching up" indicator in its own row, instead of a banner above the totals that didn't say which agent was working. A wave crosses that agent's days not read yet, and a day fills in as soon as content from it is analyzed. Each agent's seven days now form a single bar instead of a row of checkbox-like squares, and days before the agent was set up are striped.
